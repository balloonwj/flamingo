FlamingoIM 使用教程

FlamingoIM 是一套企业即时通讯系统，包括员工使用的 PC 客户端、企业管理员与平台运营使用的管理控制台 flamingoAdmin。 本教程按角色分为三部分，每个功能都配有操作步骤与界面截图。

怎样阅读本教程

  • 员工：从第一部分开始，先读「快速开始」和「认识主面板」，其余章节按需查阅。
  • 企业管理员：阅读第二部分，了解如何管理本企业的组织架构、员工、功能开关与内容安全。
  • 平台超级管理员：阅读第三部分，了解企业入驻、平台公告与客户端版本发布。
  • 页面顶部的搜索框可以按关键字查找任何功能，按 / 可直接把光标移到搜索框；点击任意截图可查看大图。
关于示例数据本教程的截图来自一套演示环境：示例企业「明远科技有限公司」、员工罗俊辉、赵卓轩、周思源等均为虚构，界面上的地址、端口等以你所在企业的实际配置为准。
