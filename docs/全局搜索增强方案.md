# 全局搜索增强方案

2026-10-04 用户在主面板全局搜索（「消息」「文件」标签，见 `UI/BalloonSearch/SearchDropdown`）完成后，要求把下面三类十项优化「挨个做，全部做完再汇报」。本文记录方案与进展。

## 1. 现状（2026-10-04 调查）

- **键盘**：主面板搜索框是布局 XML 里的普通 `DuiEdit`（`BalloonMainLayout.cpp`，id 200）。主面板只处理它的 `DUIN_VALUECHANGED`、`DUIN_EDIT_ESCAPE`、`DUIN_KILLFOCUS`；`DuiEdit` 不为上下方向键发通知，Tab 被 `DuiHost` 截去做焦点遍历。主面板消息映射在 `CHAIN_MSG_MAP(DuiFrameWindow)` 之前可以先收 `WM_KEYDOWN`，不需要改 balloonui。
- **按账号存储**：`CUserConfig`（`Session/UserConfig.h`，每账号一个 ini），没有现成的字符串列表接口；非 ANSI 文字用 `cfgtext::EncodeConfigText` 编码后写入。
- **聊天记录管理器**：`CBalloonHistoryWindow::OpenManager` 没有预填左栏搜索词的公开入口。
- **文件**：聊天文件的本地路径由 `balloonchatwnd::ResolveLocalFilePath` + `IsLocalFileUsable` 判定，打开 / 打开所在文件夹有现成的 `HandleLocalFileAction`；群文件下载后不登记本地路径。
- **本地库**：`CV2MsgStore` 回滚日志模式、全部读写共用一把互斥锁；客户端编入的 SQLite 3.53.1 源码带 FTS5，但没有定义 `SQLITE_ENABLE_FTS5`。
- **服务端**：`t_chatmsg.f_content` 由 jsoncpp 1.9.0 写出，中文是 `\uXXXX`，`cmd_search_messages`（1515）对它 `LIKE` 搜不到中文；1515 也没有过滤已撤回的消息、没有遵守「新成员不能看入群前历史」。`cmd_global_search`（1904）只在 `Protocol.h` 里占了号。
- **部门 / 公告 / 备忘 / 接龙**：部门在主面板 `m_departments`，没有「按部门定位树节点」；群公告客户端没有缓存；备忘在 `CMemoCenter::Instance().Book()`，有 `OpenFromReminder(memoid)`；接龙的标题与说明已写进本地库 `search_text`，「消息」标签本来就能搜到。

## 2. 分期

### 第 1 期　交互

| 步骤 | 内容 |
| --- | --- |
| 1a | **键盘操作**：上下键在结果行之间移动（选中行画选中底色、滚动到可见），回车打开选中行（没有选中时打开第一行），`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换标签。主面板先收 `WM_KEYDOWN`，只在搜索框有焦点且下拉在显示时处理，其余放行。纯逻辑 `SearchSelection`（单测 KS） |
| 1b | **最近搜索**：搜索框获得焦点且为空时，下拉显示最近 10 个关键字（点一下填回搜索框并搜索），附「清空」；打开搜索结果或在搜索框里按回车时记一次。按账号存在 `CUserConfig`。纯逻辑 `RecentSearchList`（单测 RS） |
| 1c | **在聊天记录管理器里看全部**：「消息」标签末尾加「在聊天记录管理器中查看全部」，打开管理器并把关键字填进左栏搜索框。消息记录窗新增公开方法 `OpenManagerWithSearch` |
| 1d | **文件结果的快捷操作**：本机有完整文件的聊天文件行，悬停时行右侧显示「打开」「打开所在文件夹」两个图标；文件夹传输记录在本机有落点时显示「打开文件夹」。`MainPanelListItem` 的悬停图标从单个「定位」扩展为最多两个动作图标 |

### 第 2 期　性能

| 步骤 | 内容 |
| --- | --- |
| 2a | **独立连接 + WAL**：本地库切到 WAL、设忙等超时；后台查询线程自己开一个连接，不再与界面线程抢同一把锁 |
| 2b | **FTS5 全文索引**：打开 `SQLITE_ENABLE_FTS5`；`t_msg_fts`（无内容表 `content=''` + `contentless_delete=1`，trigram 分词，按 rowid 对应 `t_msg`）+ 三个触发器保持同步；存量库由后台线程分批回填，回填完之前与少于 3 个字的关键字仍走 `LIKE`。三个跨会话搜索都改用它：全文索引只用来缩小候选行，候选行上仍判原来的 `LIKE`，结果与只用 `LIKE` 完全相同（单测 FTS） |
| 2c | **可中断的查询**：同一窗口、同一种查询有新请求时，对后台连接调 `sqlite3_interrupt` 中止正在执行的旧查询，旧结果不投递 |

### 第 3 期　范围

| 步骤 | 内容 |
| --- | --- |
| 3a | **服务端会话内搜索支持中文**：`t_chatmsg` 新增 `f_search_text`（纯文本，口径与客户端 `BuildSearchText` 相同，去掉 4 字节字符以兼容 MySQL utf8），存消息与编辑消息时生成，存量行在启动后分批回填；1515 改查这一列，并补上「已撤回不返回」「新成员不看入群前历史」 |
| 3b | **服务端 1904 全局搜索**：按会话汇总本人可见的全部聊天记录命中（单聊双向、本人所在的群，遵守删除 / 清空 / 可见范围 / 入群时间 / 撤回），并附带本人所在群的群公告命中；协议文档补请求与应答 |
| 3c | **客户端接 1904**：「消息」标签末尾加「搜索服务器上的聊天记录」，结果分「服务器上的聊天记录」「群公告」两段；点聊天记录结果打开该会话的消息记录（按关键字筛选）并跳到命中那条的日期，本地还没有那天的记录时由消息记录窗「跳到这一天」的机制往前拉取到那天再定位；点群公告打开群聊窗的公告页 |

## 3. 约束

- 不改 balloonui（键盘拦截放在主面板消息映射里）。
- 窗口私有消息、`FMG_MSG_*` 按开发约定文档第 6 条分配并登记；界面文字按第 8 条用 `TR` 系列并重跑 `i18n_extract.py`。
- 服务端新列同时改 `table_mysql.sql`（再跑 `tools/gen_table_sqlite.py`）与 `MysqlManager.cpp` 的字段表。

## 4. 进展记录

全部十项于 2026-10-04 完成（未提交）。客户端单测、服务端单测（Windows 与 WSL g++ 两条构建路径）全部通过，见各步说明。

- **1a 键盘操作**：`SearchKeyboard.h/.cpp`（`SearchSelection`、`NextAvailableTab`，单测 KS1～KS4）；主面板在 `CHAIN_MSG_MAP` 之前先收 `WM_KEYDOWN`（`OnSearchNavKeyDown`），只在搜索框有焦点、下拉在显示时转给 `CSearchDropdown::HandleNavigationKey`；选中行由 `MainPanelListItem::SetKeySelected` 画悬停底色。
- **1b 最近搜索**：`RecentSearchList.h/.cpp`（单测 RS1～RS5）；`CUserConfig` 的 `[Search] Recent`；下拉的 `ShowRecent` 隐藏标签栏、列出关键字与「清空」，点关键字或「清空」经 `WM_APP + 0x6D` 延后处理；打开任一结果时记一次。
- **1c 在聊天记录管理器里看全部**：`CBalloonHistoryWindow::OpenManagerWithSearch`（左栏折叠时展开、限定的范围恢复为全部会话），下拉「消息」标签末尾的按钮。
- **1d 文件结果的快捷操作**：`MainPanelListItem` 的悬停按钮改为一组（`SetHoverActions`，定位 / 打开文件 / 打开所在文件夹，单测 GSR4）；「按记录找本机文件」抽成 `HistoryLocalFile.h` 的 `ResolveRecordLocalPath`，消息记录窗与搜索下拉共用；哪类行给哪些按钮由 `PickFileHitActions` 决定（单测 GST15）。
- **2a 独立连接 + WAL**：`CV2MsgStore::Open` 切 WAL、设 3 秒忙等待并记下库路径；`CV2MsgSearchWorker::Start` 按路径另开一条连接（内存库、未打开时退回共用连接）。单测 W10、W11（读事务进行中写库立即成功）。后台查询从此不再与界面线程争用同一把锁。
- **2b FTS5 全文索引**：见上表。两处与原计划不同：一是不用外部内容表，改用 `contentless_delete` 的无内容表，删除与覆盖只需 rowid，回填与触发器重复写同一行也不会出现重复项；二是触发器里显式先删后插——触发器内语句的冲突处理方式会被外层语句覆盖，`Upsert` 撞主键走 `DO UPDATE` 时 `INSERT OR REPLACE` 不起作用（单测 FTS4 发现）。单测 FTS1～FTS6，基准 FTSB（隐藏）。
- **2c 可中断的查询**：同一窗口、同一种查询有新请求时置中断标志并调 `sqlite3_interrupt`；另装进度回调检查这个标志，覆盖「登记为正在执行、语句还没开始」这段时间（只调 `sqlite3_interrupt` 时这种时刻不起作用，单测 W12 发现）。被中断的结果不投递；`Stop` 时同样中断。
- **3a 服务端会话内搜索支持中文**：`MessageSearchText.h/.cpp`（单测 STX1～STX4）；`t_chatmsg.f_search_text`；入库、改写内容时生成；`chatserver` 启动后在主循环上每 200 毫秒回填 200 行；1515 查新列（未回填的行退回查 `f_content`），排除已撤回、按入群时间过滤，关键字里的 `% _ !` 按普通字符匹配。
- **3b 服务端 1904**：`GlobalSearchProtocol.h/.cpp`、`MessageManager::globalSearchConversations`、`GroupManager::searchAnnouncements`、`ChatSession::onGlobalSearch`（单测 GLS1～GLS5）；协议文档 10.25 节。
- **3c 客户端接 1904**：`net/GlobalSearchProtocolClient`（单测 GSP1～GSP3）、`FMG_MSG_V2_GLOBAL_SEARCH`（`WM_USER + 4414`）、下拉按钮经 `WM_APP + 0x6E` 延后发请求；请求状态复用 `GroupFileSearchState`；`CBalloonHistoryWindow::OpenForConversationAtTime` 打开并跳到命中那天。实现与原计划不同之处见上表。
- **3d 搜部门**：`SearchCandidateCache::SyncDepartments`（单测 SCC8）、`BuildDepartmentParentPath`（单测 GST16）；主面板记下「部门 id → 树节点」，`LocateDepartmentInTree` 与联系人定位共用 `ScrollContactTreeTo`。
- **3e 搜备忘**：`BuildMemoHitTexts`、`MemoStartToSystemTime`（单测 GST17、GST18）；「全部」标签群组之后最多列 5 条，点击经 `CMemoCenter::OpenFromReminder` 打开。

### 追加的两项（2026-10-04 用户在核对界面时提出）

- **搜索框清除按钮**：主面板搜索框从 `<edit>` 换成 balloonui 现成的 `<searchbox>`（`DuiSearchBox`，继承 `DuiEdit`）：左侧放大镜，文字非空时右侧出现叉号，点叉号清空文字，效果与手动删光相同（焦点留在搜索框，下拉改为显示最近搜索）。主面板按 `DuiEdit` 处理它的代码与通知不用改。单测 M10。
- **真实界面核对**（截图 `snapshots/global_search_v3_*.png`）：备忘段、×、细滑块的拖动与点轨道、文件行的两个快捷按钮都与设计一致。两点测试手段上的限制：一是用 `PostMessage` 模拟鼠标移动时，`DuiHost` 的 `TrackMouseEvent` 会立即收到 `WM_MOUSELEAVE`，悬停状态保留不住，快捷按钮改用键盘选中（同一绘制条件）核对；二是测试窗口没有系统焦点时，`DuiHost::OnKillFocus` 已清掉搜索框的焦点标志，点 × 后不会显示最近搜索（按设计如此），投递一条 `WM_SETFOCUS` 模拟窗口获得焦点后，点 × 即显示最近搜索。
- **结果区滚动条**：`UI/BalloonSearch/SearchResultScrollView`（继承 `DuiScrollView`）直接使用 balloonui 统一的悬浮式细滑块（开发约定文档 UI 约定第 1 条），不再自绘。单测 SRS1～SRS4。
