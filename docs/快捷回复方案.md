# 快捷回复方案

2026-10-06 与用户逐项确认。适用于 PC 客户端单聊窗、群聊窗：发送按钮右侧 ▾ 菜单最上方放三条「快捷回复」，点一下就把这条文字发出去；三条文字在系统设置的「聊天」页里修改。属于 12 项新功能的第一批（同批另见 `docs/撤回后重新编辑方案.md`、`docs/备忘与提醒方案.md` §8、`docs/群管理接入方案.md` §14）。

## 1. 已定事项

| 事项 | 结论 | 来源 |
| --- | --- | --- |
| 条数 | 固定三个位置；留空的位置不在菜单里显示，三条都空时菜单里不出现快捷回复这一组 | 默认 |
| 点击后 | 直接把这条文字作为文字消息发出去，输入框里的内容、待发的引用和 @ 都不动 | 用户确认 |
| 默认文字 | 「收到」「好的，稍后回复」「正在开会，稍后联系」，随界面语言翻译 | 默认 |
| 保存位置 | 本机，按账号区分，写在本人账号的 ini 里，不上传服务端；换电脑要重新设置 | 用户确认 |
| 修改入口 | 系统设置「聊天」页新增「快捷回复」一组，三个单行输入框，旁边一个「恢复默认」；▾ 菜单末尾加「设置快捷回复…」直接打开这一页 | 默认 |
| 每条长度 | 最多 50 个字 | 默认 |

## 2. 现状（据实证）

本节记的是 2026-10-06 动手前的代码现状，行号只对当时的代码成立；▾ 菜单此后已改为共用模块 `ChatSendMenu`（见第 8 节）。

- **▾ 菜单**：单聊窗、群聊窗各写了一份，没有共用代码（`flamingoclient/Source/UI/BalloonChatWnd/BalloonChatWindow.cpp:4797-4843`、`BalloonGroupChatWindow.cpp:2424-2470`），用 `balloonwjui::DuiMenu` 同步弹出，只有「按 Enter 发送消息」「按 Ctrl+Enter 发送消息」两个勾选项，命令 id 是函数内的局部常量。菜单高度按 `GetCount() * 32` 估算（`:4830`、`:2457`），加了分隔线或标题后会不准。菜单文字里的 `&` 会被当成助记符（`DuiMenu.h:90`）。
- **发文字**：没有不经输入框的发送入口。最底层是单聊 `SendTextPartReal`（`BalloonChatWindow.cpp:4890`）、群聊 `SendGroupTextPart`（`BalloonGroupChatWindow.cpp:3167`），但两者都会带上并清掉输入框待发的引用（`m_pendingQuote`），群聊还会拿待发的 @ 候选重扫正文。在线检查（`CheckOnlineFor`）只在 `DoSend` 里做。
- **禁言与敏感词**：群聊窗发送前不检查禁言，敏感词也只在服务端拦截；被拒时服务端回错误码（306 禁言、507 敏感词），经 `OnSendChatAckFailed` 把气泡标为发送失败（`ChatSendLimit.cpp:65-90`）。
- **设置「聊天」页**：代码拼装（`UI/BalloonSettings/BalloonSystemSettingDlg.cpp` 的 `BuildChatPage`，`:905-957`），改了即生效，没有保存按钮。文字框的先例是离开 / 忙碌自动回复：输入时只改内存，失去焦点或关窗时存盘（`:722`、`:748`），限长用 `SetMaxLength`（`AutoReplySettingsRows.cpp:29`）。
- **账号 ini 的写法**：以自动回复为例，节名 `[AutoReply]`（`Session/UserConfig.cpp:334-349` 读、`:435-440` 写），中文先转 UTF-8 再写成十六进制，ini 里是纯 ASCII（`Session/ConfigTextCodec.h:27-39`）。
- **系统设置窗**只能打开到默认页（`CBalloonSystemSettingDlg::OpenSettings(HWND)`，主面板调用点 `BalloonMainPanel.cpp:11799`），内部有 `ShowPage(int)`。

## 3. 设计

### 3.1 配置

- 账号 ini 新增 `[QuickReply]` 节，键 `Text1`、`Text2`、`Text3`，值用 `ConfigTextCodec` 编码。
- **区分「没设过」和「设成空」**：键不存在时取默认文字；键存在但值为空，表示用户特意清空了这一条，不显示。与自动回复「空串即默认」的约定不同，因为快捷回复允许某一条为空。
- 「恢复默认」删除三个键，回到默认文字。
- `CUserConfig` 增加读写三条文字的方法；默认文字用 `TR_NOOP` 标记，读取时再经 `TR` 翻译。

### 3.2 ▾ 菜单

- 新增 `UI/BalloonChatWnd/ChatSendMenu.{h,cpp}`，单聊窗和群聊窗共用：根据快捷回复与当前发送键生成菜单项，返回点了哪一项（快捷回复第几条 / 发送键 / 设置快捷回复）。两个窗口原来各自的那份菜单代码改为调用它。
- 菜单从上到下：标题「快捷回复」，非空的快捷回复（每条一行），分隔线，「按 Enter 发送消息」「按 Ctrl+Enter 发送消息」，分隔线，「设置快捷回复…」。三条都为空时去掉标题和第一条分隔线。
- 菜单里每条快捷回复只显示一行：换行显示成空格，超过 20 个字截断并加「…」；`&` 转义为 `&&`。点击后发送的是完整原文。
- 菜单高度改用 `DuiMenu::MeasureSize()` 计算，不再按条数估算。

### 3.3 发送

- 单聊窗、群聊窗各新增一个发送快捷回复的方法：先做在线检查，再把文字按输入框发送路径相同的规则转换成发送正文，生成乐观气泡并发送；**不读也不清**输入框、待发引用和待发 @ 候选。
- 发送直接用两个聊天窗已有的 `SendPlainText`（不带引用与 @、不读也不清输入框），不需要拆分 `SendTextPartReal` / `SendGroupTextPart`（见第 8 节）。
- 禁言、敏感词照旧由服务端判断，被拒时气泡标为发送失败，与手工输入发送的结果一致。

### 3.4 顺带修复 BUG-119（发送键两份配置不同步）

▾ 菜单要重写，顺带把发送键统一为账号 ini 的 `[ChatDlg] EnableEnterToSend`：`ChatSendMode` 改为读写 `CUserConfig`；账号 ini 里还没有这一项时，用 `flamingo.ini` 的 `[chat] sendmsgkey` 作为初值读一次，以免老用户升级后发送键被重置。改动后设置页与 ▾ 菜单任一处修改，另一处都立即看得到。用户 2026-10-06 确认在本批顺带处理。

### 3.5 系统设置「聊天」页

- 在「离开 / 忙碌自动回复」一组下方新增「快捷回复」一组：小标题、三个单行输入框（占位文字「快捷回复 1」等，最多 50 个字）、「恢复默认」按钮。失去焦点或关窗时存盘，做法与自动回复相同。
- `CBalloonSystemSettingDlg::OpenSettings` 增加一个指定初始页的重载。聊天窗点「设置快捷回复…」时，投一条消息请主面板打开系统设置的「聊天」页（新增一条 B 段消息，号取 4500 档，按开发约定文档 UI 约定 6 登记）。

## 6. 实机核对清单

1. 单聊窗、群聊窗的 ▾ 菜单里都能看到三条默认的快捷回复，点一条立即发出。
2. 输入框里打了一半的字、挂着的引用，在点快捷回复之后都还在。
3. 在设置「聊天」页把第二条清空、第一条改成别的文字，回到聊天窗，菜单里只剩两条且第一条是新文字。
4. 点「设置快捷回复…」直接打开系统设置的「聊天」页。
5. 被禁言的群里点快捷回复，气泡显示发送失败，提示与手工发送时相同。
6. 切换界面语言为英文，默认的三条快捷回复显示为英文。

## 8. 实施记录（2026-10-06）

与方案的出入：

- **发送路径**：两个聊天窗本来就有 `SendPlainText`（屏幕共享第 25 期加的，不带引用与 @、不读也不清输入框），快捷回复直接用它，没有再拆 `SendTextPartReal` / `SendGroupTextPart`（§3.3 的拆分不需要了）。正文经 `QuickReplyBody`（内部是 `balloonchat::BuildSendBody`）编码，与输入框发送的纯文字同一规则。
- **设置页布局**：系统设置窗没有滚动条、高度按内容逐行算定，三个输入框各占一行会把窗口撑到约 900 像素，小屏放不下。改为标题行（「快捷回复」+ 说明 +「恢复默认」）下面一行**并排**三个单行输入框，窗口初始高度随之加高（`BalloonSystemSettingDlg.cpp` 的 `kDlgClientH`）。
- **发送键（BUG-119）**：`ChatSendMode` 增加 `IChatSendModeStore` 与 `BindChatSendModeStore`；登录加载账号配置后由会话控制器绑定 `CSendModeConfigStore`（`UI/BalloonMain/SendModeConfigStore.{h,cpp}`），登出时解绑。设置页改发送键后投 `FMG_MSG_SEND_MODE_CHANGED`（`WM_USER + 4530`）请主面板刷新已打开聊天窗的左下角提示。
