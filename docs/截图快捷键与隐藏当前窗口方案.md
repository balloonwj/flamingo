# 截图快捷键、截图时隐藏当前窗口与截取全屏方案

2026-10-05 与用户逐项确认。适用于 PC 客户端单聊窗、群聊窗的截图工具（截图界面在 `FlamingoScreenshot.dll` 里，代码在 `flamingoclient/FlamingoScreenshot/Capture/`；托盘菜单的「截图」与未登录时截图见 `docs/截图独立模块方案.md`）。

## 1. 已定事项

| 事项 | 结论 |
| --- | --- |
| 截图快捷键 | 全局快捷键，默认 `Alt+Z`；可在系统设置「快捷键」页修改，清空即停用 |
| 快捷键的组合规则 | 至少带 Ctrl 或 Alt，可再加 Shift；主键限 A~Z、0~9、F1~F12；不得与本程序的 `Ctrl+Alt+D`（打开主面板）、`Ctrl+Alt+R`（录屏）重复 |
| 前台是单聊 / 群聊窗时按快捷键 | 由该窗口发起截图，与点工具栏剪刀相同 |
| 前台是其他程序时按快捷键 | 截图不绑定会话：操作栏为「重选 / 保存 / 取消 / [完成]」，「完成」为橙色主按钮，把截图放进剪贴板；选区内双击等于「完成」 |
| 截取全屏 | 只截鼠标所在的那块显示器；下拉菜单「截取全屏」与截图界面里的 Ctrl+A 效果相同 |
| 截图时隐藏当前窗口 | 只去掉发起截图的那个聊天窗；默认勾选；下拉菜单的勾选项与「聊天」页开关是同一个配置 |
| 下拉菜单里的快捷键文字 | 写在括号里，如「截图（Alt+Z）」，不改 balloonui |
| 设置页「打开主面板」 | 以程序实际注册的 `Ctrl+Alt+D` 为准（BUG-99） |

## 2. 布局

- **聊天窗工具栏**：剪刀右边新增 14 像素宽的 ▾（单聊 id 442，群聊 id 537）。剪刀的悬停提示为「截图（Alt+Z）」，快捷键停用时为「截图」；▾ 的悬停提示为「截图选项」。
- **▾ 菜单**：「截图（Alt+Z）」「截取全屏」，分隔线，勾选项「截图时隐藏当前窗口」。
- **截图界面**：
  - 框选之前，在鼠标所在显示器的顶部居中显示提示条「拖动鼠标框选区域 · Ctrl+A 截取全屏 · Esc 退出」，开始拖动后隐藏。
  - 工具栏与尺寸读数只在选区所在的显示器内放置；选区上下都放不下工具栏时（例如全屏选区），工具栏放进选区内的右下角，尺寸读数放进选区内的左上角。
- **系统设置**：
  - 「快捷键」页的「截图」一行改为可录入的键帽，右边有「恢复默认」；标题「截图」下方的副标题是一行提示（录入说明、组合不合规的原因，或「已被其他程序占用」，后两种为红色），与设置页其它行的「标题 + 副标题」样式一致。「打开主面板」一行的键帽文字改为由程序实际注册的组合生成（`Ctrl + Alt + D`）。
  - 「聊天」页新增「截图时隐藏当前窗口」开关。

## 3. 实现要点

- **排除聊天窗**：抓屏前对聊天窗调用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，截图界面显示出来后恢复原值。2026-10-05 实测（`tmp/shotwda/wda_test.exe`）：设置后立即用 `BitBlt` 抓屏，该窗口区域抓到的是背后的窗口（背后绿色窗口占比 1.000，红色 0.000，黑色 0.000），恢复后立即重新可见；分层窗口结果相同。系统低于 Win10 2004（build 19041）时改为先隐藏窗口、`DwmFlush` 后抓屏，截图界面显示后再恢复显示。
- **全局快捷键**：注册在主面板上（热键 id 1003，`MOD_NOREPEAT`），程序启动、主面板建好后即注册（`CAppShell::Startup`），未登录也有效，按设置随时重新注册；设置页录入新组合期间，暂时注销本程序的三个全局快捷键，录入结束后恢复。
- **防重入**：截图界面的局部消息循环会把 `WM_HOTKEY` 照常派发给主面板，所以 `CScreenCaptureOverlay::Run` 在已有截图进行时直接返回。
- **配置**：全局配置 `config/flamingo.ini` 的 `[screenshot] hotkey`（高 16 位为 `MOD_*` 组合、低 16 位为虚拟键码，0 表示停用，缺省为 Alt+Z）、`[screenshot] hidewindow`（缺省 1），所有账号共用（`Feature/Screenshot/ScreenshotPrefs`）。账号配置里的 `[Settings] ScreenshotHotkey` / `ScreenshotHideWindow` 只作为升级后第一次登录时的迁移来源。

## 5. 实机核对清单

截图界面会盖住整个桌面并抓下真实的屏幕内容，按 `docs/界面自动化验证原理.md` 第 12 节「隐藏桌面与可见桌面的规矩」（12.5），实机效果由人来核对：

1. 单聊窗、群聊窗工具栏剪刀右边出现 ▾；悬停剪刀提示「截图（Alt+Z）」，悬停 ▾ 提示「截图选项」。
2. 点 ▾ 弹出菜单：「截图（Alt+Z）」「截取全屏」、分隔线、「截图时隐藏当前窗口」（默认打了勾）。
3. 勾选「截图时隐藏当前窗口」时点剪刀：截图里看不到这个聊天窗，看到的是它背后的内容；聊天窗本身不闪烁。取消勾选后再截，聊天窗出现在截图里。系统设置「聊天」页的开关跟着菜单的勾选状态变化。
4. 框选之前，鼠标所在显示器的顶部居中有提示条「拖动鼠标框选区域 · Ctrl+A 截取全屏 · Esc 退出」，开始拖动后消失、点「重选」后重新出现；多显示器时提示条跟着鼠标换到另一块屏上。
5. 菜单选「截取全屏」，或在截图界面按 Ctrl+A：选区是鼠标所在的整块显示器，尺寸读数在选区内左上角，两条工具栏在选区内右下角；选区仍可拖边缩小。
6. 聊天窗在前台时按 Alt+Z：与点剪刀相同（操作栏带「发送到对话框」「发送」）。
7. 在浏览器等其他程序里按 Alt+Z：操作栏为「重选 / 保存 / 取消 / [完成]」；点「完成」或在选区内双击后，截图在剪贴板里，可以粘贴到其他程序。
8. 截图进行中再按一次 Alt+Z：没有反应（日志 `screenshot: another capture is in progress`）。
9. 系统设置「快捷键」页：「打开主面板」显示 `Ctrl + Alt + D`；点「截图」的键帽，边框变橙并提示「请按下快捷键」，按住 Ctrl+Alt 时显示 `Ctrl + Alt + …`；按下 Ctrl+Shift+S 后键帽变为新组合并立即生效；按 Ctrl+Alt+D 提示「与「打开主面板」的快捷键重复」且保持原组合；按 Backspace 停用，副标题提示「已停用，点击键帽可重新设置」，剪刀的悬停提示变为「截图」；点「恢复默认」回到 Alt+Z。
10. 与其他程序冲突（例如先让别的程序占用 Alt+Z 再启动本程序）：设置页副标题以红字提示「Alt+Z 已被其他程序占用，请换一个组合」。
