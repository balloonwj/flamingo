# 群成员部门树方案

2026-10-06 与用户确认。12 项新功能的第二批之一（同批另见 `docs/会话标为未读方案.md`、`docs/消息提醒模式与消息盒子方案.md` §12）。群聊窗右侧「成员」页签的列表可以在「平铺」与「按组织结构」两种视图之间切换：按组织结构时，成员按公司部门层级显示成可折叠的树。

## 1. 已定事项

| 事项 | 结论 | 来源 |
| --- | --- | --- |
| 形态 | 两种视图可切换，记住上次的选择（按账号，所有群共用一个设置） | 用户确认 |
| 树的内容 | 只显示含本群成员的部门及其上级部门；部门名后带人数（这个部门及下级部门里的本群成员数，同一个人只算一次）；不属于任何部门的成员放在最后的「未分配部门」里 | 用户确认 |
| 兼属 | 一个人属于多个部门时，在每个所属部门下都出现，兼属部门那一行的名字后加「兼」字标记 | 用户确认 |
| 实现方式 | 扩展现有的自绘成员列表：新增「部门标题行」小控件（折叠箭头 + 部门名 + 人数），成员行加缩进与「兼」标记；滚动、悬停、右键菜单、在线状态、搜索都沿用现有实现，不改 balloonui | 用户确认（UI 约定 2 要求的对齐已完成） |
| 切换入口 | 搜索框右边一个链接样式的文字按钮，平铺时写「按部门」，部门树时写「平铺」 | 默认 |
| 折叠 | 默认全部展开；点部门标题行折叠 / 展开它的下级；折叠状态只在本窗口开着时保留 | 默认 |
| 部门内的顺序 | 下级部门在前、成员在后（与主面板通讯录相同）；部门按部门排序值，成员先按群角色（群主、管理员、成员）、再按部门内排序值 | 默认 |
| 搜索 | 部门树视图下按名字过滤成员，命中成员所在的部门（及上级）照常显示并自动展开，没有命中成员的部门隐藏 | 默认 |

## 2. 现状（据实证）

- **成员列表全部自绘**：`GroupMemberList`（继承 `DuiControl`）按固定行高 38 摆放子行 `GroupMemberItem`，滚轮、细滑块（`ChatScrollThumb` + `ChatScrollFade`）、右侧留边都由它自己处理（`UI/BalloonChatWnd/GroupMemberList.cpp`）；排序 `OrderMemberIndicesByRole`（`GroupMemberOrder.cpp:51`）；过滤 `SetFilterKeyword` 隐藏未命中的行。成员行的右键、双击经宿主投 `WM_CHAT_MENTION_ACTION`。
- **成员数据没有部门信息**：1304 应答的 `net::GroupMemberItem` 只有 userid、角色、群名片、昵称、头像、入群时间与禁言字段（`net/GroupProtocolClient.h`）。
- **组织架构在主面板**：1201 应答的 `DepartmentItem`（deptid、name、parentdeptid、deptorder、members）与 `DeptMemberItem`（userid、position、isprimary、memberorder）（`net/ContactsProtocolClient.h`），主面板持有 `m_departments`（`BalloonMainPanel.h`）。
- **可参考的纯函数**：`BuildMemberPickerTree`（`UI/BalloonMain/MemberPickerTreeModel.cpp`）已经做了剪掉没人的部门但保留上级、成环保护、排序、兼属多处出现、末尾「未分组」；但成员排在子部门前面、节点不带兼属标记与人数、显示名取通讯录昵称，所以按它的写法另写一个。
- **界面偏好的存法**：可参照消息记录窗的 `[HistoryDlg] ManagerPaneWidth / ManagerCollapsed`，设置后立即存盘。顺带发现 `UserConfig.cpp` 读群聊窗高度时用的是 `GroupDlgWidth` 键（读单聊窗高度的 `ChatDlgWidth` 同样如此），记为 `bugs.md` 的 BUG-121，不在本期修。

## 3. 设计

- **纯函数** `UI/BalloonChatWnd/GroupMemberDeptTree.{h,cpp}`：输入本群成员（userid、角色）与部门数组，输出扁平的行序列。每行是部门标题（部门 id、名字、层级、人数）或成员（userid、层级、是否兼属、所在部门 id）。规则按 §1，并做成环保护（部门的上级链出现环时按顶级部门处理）。
- **部门标题行** `GroupDeptHeaderItem`（新增自绘小控件，与 `GroupMemberItem` 同一行高、同一套悬停底色）：折叠箭头、部门名、人数；点一下发通知给列表切换折叠。
- **成员行**：`GroupMemberItem` 增加缩进量与「兼」标记（名字后的灰色小字）。
- **列表**：`GroupMemberList` 增加视图模式；部门树视图下按纯函数的输出建行，折叠时隐藏下级行并重排（UI 约定 5）。搜索在部门树视图下按 §1 处理。`SetMemberPresence` 与头像回刷改为更新这个人的所有行。
- **数据**：主面板新开群聊窗时、以及收到通讯录（1201 / 1404 后重拉）时，把部门数组推给已打开的群聊窗（`SetOrgDepartments`）。
- **切换与记忆**：成员页签的搜索框改成一行（搜索框 + 「按部门 / 平铺」切换按钮；最初是文字链接，2026-10-07 晚改为图标按钮，见 §7 末条）；`CUserConfig` 新增 `[GroupDlg] MemberView`（0 平铺、1 部门树），切换时立即存盘。

## 6. 实机核对

1. 群聊窗「成员」页签，点搜索框右边的「按部门」，列表变成部门树，部门名后有人数；再点「平铺」恢复原样。
2. 关窗重开、换一个群打开，仍是上次选的视图。
3. 兼属两个部门的同事在两处都出现，兼属那一处名字后有「兼」。
4. 点部门标题折叠 / 展开，下面的行随之收起 / 出现，滚动条正常。
5. 部门树视图下搜索一个名字，只剩命中的人和他所在的部门。
6. 成员上下线时，部门树里他的每一行在线状态都跟着变。

## 7. 实施记录（2026-10-07）

按 §3 实现，测试用例见 §5。与方案不同或方案没写到的地方：

- **纯函数** `UI/BalloonChatWnd/GroupMemberDeptTree`：成环时沿上级链往上走，走回已经走过的部门就把当前这一步的上级断开、让它成为顶级部门，所以每个部门只出现一次。「兼」只标在「他在别处有主部门」的人身上，数据里一个主部门都没有的人不标。同一部门内成员按群角色、部门内排序值、服务端返回的顺序排。
- **部门标题行** `GroupDeptHeaderItem`：与成员行同一行高 38、同一套悬停底，按层级每层缩进 14 像素（6 层封顶）；名字加粗，人数是名字后面的灰色「(n)」。点击由它直接调父列表的 `ToggleDeptCollapsed`，没有走控件通知；悬停变化时按 UI 约定第 9 条自己重画。
- **列表** `GroupMemberList`：新增 `AddRow(行, 父行下标)` / `ClearRows` / `SetTreeMode` / `ToggleDeptCollapsed`；折叠状态按部门 id 记在列表里，重建行时保留，窗口关闭即丢。搜索时部门标题行的箭头一律画成展开、点击不切换。`HasNoMatches` 改为只看成员行。
- **成员行**：`GroupMemberItem::SetTreeLayout(层级, 兼属)`，头像按层级右移，「兼」字是名字后面的 11 像素灰字。
- **群聊窗**：成员行的构造在 `UI/BalloonChatWnd/GroupMemberPanelKit` 的 `MakeGroupMemberRow`（与帖子群成员面板共用），按视图重建抽成 `RebuildMemberRows`（成员到达、切换视图、部门数组更新三处调用），成员数据另存一份 `m_lastMembers`。切换按钮 id 为 539（`kGIdMemberViewToggle`），状态由 `ApplyMemberViewToggle` 设置（见本节末条）。主面板在 `EnsureGroupWindow` 与收到通讯录时调 `SetOrgDepartments`。头像回刷原本就遍历全部行，不用改；`SetMemberPresence` 改为更新同一个人的所有行。
- **配置**：`CUserConfig::IsGroupMemberTreeView` / `SetGroupMemberTreeView`，`[GroupDlg] MemberView` 只认 1，其余按平铺。
- **用例**：`Tests/GroupMemberDeptTreeTests.cpp`（MT1~MT6）。
- **切换链接改为图标按钮（2026-10-07 晚，用户认为文字链接不好看）**：539 号控件由链接样式的 `DuiLabel` 改为 `ChatIconButton`，图标是新增的 `kChatIconOrgTree`（54，组织架构图：上方一个框分出下方两个框，`ChatIcons.cpp`），宽 32。用户从三个候选里选了组织架构图（另两个是缩进树形列表、楼宇；样图 `tmp/icon_preview/member_view_icons.png`），又选了「同一图标，部门树视图下变蓝」而不是两个图标互换。`ApplyMemberViewToggle` 改为设置高亮与两态悬停提示（部门树视图下「平铺显示」，平铺视图下「按部门显示」），不再按译文重设宽度。`ChatIconButton` 新增 `GetIconKind` / `GetToggleTip` 供单测读取。用例 `GroupChatWindowLayoutTests.cpp` 的 G6i（按钮类型、位置、高亮与提示）、G6j（图标画得出来、与无序列表和入群邀请图标不同），标签 `[deptview]`；用户已实机核对通过。

## 8. 平铺视图的选中样式（2026-10-08）

**需求**：用户要求群聊成员列表有选中样式。现状（据实证）：成员行只有悬停的浅灰圆角底（`GroupMemberItem.cpp` 的 `kHoverFill` `#F2F1EE`），单击没有任何反应，双击打开单聊，右键弹成员菜单但看不出是对哪一行弹的。

**已定事项（用户逐项确认）**

| 事项 | 结论 |
| --- | --- |
| 样式 | 浅橙底 `#FFF1E8`（与悬停底同位置、同圆角）+ 左侧 3 像素宽的橙色竖条 `#FF7A45`（群聊窗的主色）。从三个候选里选定，另两个是加深灰底加粗名字、主面板同款蓝底白字；样图 `tmp/icon_preview/member_select_preview.png` |
| 范围 | 只改平铺视图；部门树视图保持原样，不显示选中，点成员行也不产生选中 |
| 交互 | 单击选中（单选）；右键先选中再弹菜单；双击照旧打开单聊；点列表空白处不取消；鼠标停在选中行上仍画选中样式 |
| 保留与清除 | 按 userid 记住，列表重建（成员到达、上下线、切换视图）后保留；搜索过滤只隐藏、不取消；选中的人离开群时取消，之后再入群不自动恢复；切到部门树视图再切回平铺时恢复 |

**实现**：不换成 balloonui 的 `DuiListBox`（部门树、过滤、滚动条都要重做），在现有自绘控件上加一项状态。`GroupMemberList` 记 `m_selectedUserId`，新增 `SelectMember`（树视图下忽略）、`SelectedUserId`、`CommitRows`（挂完一批行之后取消已离开的人的选中并刷新各行显示，由 `FillGroupMemberList` 调用，群聊窗与帖子群窗口的成员面板都经它填行，所以帖子群成员面板的平铺视图也有同样的选中）；`AddRow` 挂成员行时、`SetTreeMode` 切换时按当前视图套用选中。`GroupMemberItem` 新增 `SetSelected` / `IsSelected` 与选中样式的绘制，左键按下与右键按下（弹菜单之前）都请父列表选中本行。

**用例**：`Tests/GroupMemberSelectTests.cpp`（标签 `[memberselect]`）MSEL1 单击选中与移动、点空白不取消；MSEL2 右键先选中；MSEL3 重建保留、离开取消、过滤后恢复显示；MSEL4 部门树视图不产生选中、切回平铺恢复；MSEL5 离屏绘制取像素核对浅橙底与竖条、悬停时仍是选中样式。

**验证（2026-10-08）**：单测 `[memberselect]` 5 个用例通过，`[groupchat]`（含成员搜索）53、`[memberdepttree]` 6、`[hover]` 7、`[avataraa]` 4 个用例照常通过。实机：`tmp/threadgroup/live` 的 clientA（15:06 从当前源码编的 exe）打开「讨论小组」，单击莫梅后选中、再点江怡选中移过去，选中行取像素为 `#FFF1E8`（与设计值一致）、左侧竖条为橙色；鼠标停在选中行上仍是选中样式；右键秦明芳时先选中再弹菜单；点列表下方空白处不取消；切到部门树视图不显示选中，切回平铺后恢复。

**核对时发现的原有问题（与选中无关，据实证）**：成员行的悬停浅灰底不会随鼠标即时出现 —— `GroupMemberItem` 没有覆写 `OnMouseEnter` / `OnMouseLeave`，`GroupMemberList` 的鼠标处理也不重画（上次提交里就是这样），属于 UI 约定第 9 条那一类；实机里鼠标停在没选中的行上，取像素仍为 `#FFFFFF`。用户确认这不是问题，不修。
