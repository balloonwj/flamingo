# 群问答方案

2026-10-07 起草并实施，12 项新功能的第三批之一（同批另见 `docs/群公告接入方案.md` §14 入群必读、`docs/邀请入群方案.md` §12 加群链接）。群聊窗右侧边栏新增「问答」页签：群主和管理员维护本群的常见问题与答案，成员可以查看、搜索、把某一条发到群里；企业管理员可以在 flamingoAdmin 里配置企业级问答，应用到所选的群或全部群。第五批的机器人会用这些问答自动作答。

## 1. 已定事项

| 事项 | 结论 | 来源 |
| --- | --- | --- |
| 位置 | 群聊窗右侧边栏的第五个页签「问答」，做在 exe 里，不受将来机器人 DLL 是否加载的影响 | 用户确认 |
| 谁能维护 | 群主、管理员新增、修改、删除本群问答；普通成员只能查看、搜索、发到群里 | 用户确认 |
| 内容 | 一问一答，问题最多 128 字、答案最多 2048 字，都是纯文字；答案里的网址在卡片下方列成可点的链接 | 用户确认（答案纯文字、网址可点），长度为默认 |
| 发到群里 | 卡片上的「发到群里」把「问：……」「答：……」两段作为一条文字消息发出，走正常的发言校验 | 用户确认 |
| 企业级问答 | flamingoAdmin 新增「企业问答」页面，企业管理员（平台超级管理员代为）维护；每条可应用到本企业的全部群或所选的群 | 用户确认 |
| 企业问答在群里 | 只读，不能隐藏；带「企业」标记；本群有同一个问题（去掉首尾空白、不分大小写后相同）的问答时只显示本群的那一条 | 用户确认 |
| 「本企业的群」 | 群主所属企业即群所属企业（`t_group` 没有企业列） | 默认（据实证：`table_mysql.sql` 的 `t_group` 没有企业列） |
| 刷新 | 切到「问答」页签时拉一次；本群问答有增删改时服务端推 1339，打开着的群聊窗重拉；企业问答改动不推送，下次切到页签时生效 | 默认 |

## 2. 设计

### 2.1 服务端

- 新表：
  - `t_group_qa`：`f_id`、`f_groupid`、`f_question`、`f_answer`、`f_editor`（最后修改人）、`f_create_time`、`f_update_time`。
  - `t_enterprise_qa`：`f_id`、`f_enterprise_id`、`f_question`、`f_answer`、`f_scope`（0 全部群，1 所选的群）、`f_creator_id`、`f_creator_name`、`f_create_time`、`f_update_time`。
  - `t_enterprise_qa_group`：`f_qa_id`、`f_groupid`（`f_scope = 1` 时这条问答应用到哪些群）。
- 管理器 `GroupQaManager`：本群问答的增删改查；企业问答的增删改查；「某个群能看到的企业问答」；群解散、企业删除时清理。
- 客户端命令（群段 1336~1339）：
  - `cmd_get_group_qa`（1336）`{groupid}` → `{code, msg, groupid, items:[{id, question, answer, source, editorname, updatetime}]}`，`source` 为 `group` 或 `enterprise`。按「本群问答在前（按修改时间倒序）、企业问答在后」排，企业问答按问题去重后再与本群问答去重。
  - `cmd_save_group_qa`（1337）`{groupid, id, question, answer}`：`id` 为 0 新增，否则修改；群主、管理员；问题与答案过企业敏感词。
  - `cmd_delete_group_qa`（1338）`{groupid, id}`：群主、管理员。
  - `cmd_group_qa_changed_notify`（1339）`{groupid}`：本群问答变了，推给全体群成员。
  - 错误码：问答不存在 318；每群最多 200 条，超出 319。
- 管理接口（`/admin/qa/*.do`，错误码 160 段）：`list.do`、`add.do`、`update.do`、`delete.do`、`groups.do`（列出本企业的群供选择）。企业管理员只能管本企业，平台超级管理员须带 `enterpriseid`，与敏感词接口同一套做法。写操作记审计日志。

### 2.2 客户端

- 协议与 IUSocket：1336~1339 的构造与解析。
- 群聊窗：边栏第五个页签「问答 N」；面板顶部搜索框，中间是问答卡片列表，底部「＋ 添加问答」（群主、管理员可见）。卡片用 balloonui 现成控件组合（`DuiVBox` + `DuiLabel` + 链接样式的 `DuiLabel`）：问题（加粗）、答案（自动换行）、答案里的网址各一行链接、底部操作「发到群里」「修改」「删除」（后两个只给群主、管理员，企业问答没有）。
- 编辑窗口 `UI/BalloonChatWnd/GroupQaEditDialog`：问题输入框、答案多行输入框、保存与取消，长度超限时就地提示。
- 纯逻辑 `GroupQaModel`：搜索过滤（问题与答案里都找）、去重口径、网址提取、「发到群里」的文字。

### 2.3 flamingoAdmin

- 新页面「企业问答」（左侧导航新增一项，「退出登录」按钮挪号），列表显示问题、答案摘要、应用范围、修改时间，支持新增、修改、删除；平台超级管理员先选企业。
- 编辑窗口：问题、答案、应用范围（全部群 / 所选的群），选「所选的群」时列出本企业的群供勾选。

## 4. 实机核对

1. 群主在群聊窗「问答」页签添加两条问答，成员那边的页签随即出现。
2. 成员搜索关键词只剩命中的问答；点答案里的网址能打开浏览器；「发到群里」把问答发成一条消息。
3. 管理员在 flamingoAdmin「企业问答」添加一条应用到全部群的问答，群里切到「问答」页签能看到带「企业」标记的这一条，没有修改、删除。
4. 改成只应用到另一个群，本群看不到了；本群添加一条同样问题的问答，只显示本群的那一条。

以上四条 2026-10-07 都已由用户核对通过。

## 5. 实施记录（2026-10-07）

**服务端**

- 表：`t_group_qa`、`t_enterprise_qa`、`t_enterprise_qa_group`；解散群时一并清理 `t_group_qa`、`t_enterprise_qa_group`。
- 纯逻辑 `GroupQaProtocol`（长度检查按 UTF-8 字符计数、`mergeForGroup` 合并去重、报文编解码），读写 `GroupQaManager`，管理接口字段与范围校验 `QaAdminProtocol`；`ChatSession` 的 1336~1338 处理函数（保存与删除后推 1339），敏感词来源 17（`sensitive_source_group_qa`）；`HttpSession` 的 `/admin/qa/list.do`、`add.do`、`update.do`、`delete.do`、`groups.do`，写操作记审计 `qa.add` / `qa.update` / `qa.delete`。
- 单测 `tests/test_groupqa.cpp`（QA-S1~QA-S3）。

**客户端**

- 协议 `net/GroupQaProtocolClient`；IUSocket 收发；1336 经 `FMG_MSG_V2_GROUP_QA`（4307）、1339 经 `FMG_MSG_V2_GROUP_QA_CHANGED`（4308）回投，保存与删除的应答走通用群写操作应答，失败时主面板按错误码提示。
- 纯逻辑 `UI/BalloonChatWnd/GroupQaModel`：筛选、网址提取（只认 http / https，去掉句末标点、去重、最多 8 个）、「发到群里」的文字、本地校验、权限、空状态提示、卡片控件 id 换算（28000 起，与备忘卡片的 20000~27999 错开）。
- 卡片列表 `GroupQaCardList`：视口复用备忘页签的 `CMemoCardScrollView`，卡片高度按视口宽度用 `DuiLabel::MeasureHeight` 量出，窗口宽度变了重建；网址是链接样式的 `DuiLabel`，点了用浏览器打开。
- 编辑窗 `GroupQaEditDialog`（布局 `GroupQaEditLayout`，整窗 440×440）：保存时本地校验，通过后把结果投给宿主群聊窗（`WM_APP + 0x5C`），由群聊窗发 1337 并关窗。
- 群聊窗：边栏第五个页签「问答」（控件 id 581，面板 600 段）；第一次切到页签时拉取；卡片按钮先投 `WM_APP + 0x5B` 给自己再执行。边栏页签改为在简体中文下也按文字宽度分配（五等分时「群文件 N」放不下）。
- 单测 `Source/Tests/GroupQaTests.cpp`（`[groupqa]`，QA-C1~QA-C3）。

**flamingoAdmin**

- 接口 `Util/QaAdminApi`（单独成文件，不再往 `AdminApi.cpp` 里加），页面 `Screens/EnterpriseQaScreen`（表格复用 `ActionTable`，搜索只在本地筛选），弹窗 `Screens/EnterpriseQaModal`（群列表用带勾选框的 `DuiListBox`，群晚到时保留已勾选的群）。
- 导航项「企业问答」取 210，原来的登出按钮由 210 改为 214；`ApiTag` 取 160~164；控件 id 取 660 段；拦截记录的来源名称补上 17「群问答」。
- 单测 `Tests/EnterpriseQaTests.cpp`（EQA-1~EQA-4，即方案里的 QA-A1）。

**与方案的出入**

- 页签标题只写「问答」，不带条数；面板底部按钮叫「＋ 新建问答」。
- 编辑窗的长度检查在点「保存」时做（输入框本身也限了长度），不是边输入边提示。
- QA-C3 改为「编辑窗按设计尺寸排得下」的布局单测；面板里卡片数与按钮显隐依赖窗口与网络，留给实机核对。
