# 聊天卡片美化方案

2026-10-14 起。范围：单聊、群聊消息列表里的各类卡片（非文字消息），以及消息记录窗、聊天记录管理器、合并记录查看窗里复用同一套绘制的文件、代码片段、Markdown 卡片。文字气泡、图片、头像、列表底色不在本方案内（气泡另有对比页，待定）。

效果对比页：`tmp/chatstyle/cards/卡片对比.html`（左侧为隐藏用例 CARDSHOT1 的实拍，右侧为按新规格写的效果图）。

## 1. 已定事项（2026-10-14 逐项确认）

1. **本人发出的卡片也用白底**，与对方的卡片一致，靠左右位置区分发送方。现在本人发出的卡片是浅橙底（`kBubbleSelf`，与本人的文字气泡相同）。
2. **图标块按类型着色，十种颜色**（见第 3.1 节）。按钮无论哪种卡片都统一用品牌橙。
3. **保留底部类型标签**：每张卡片底部左侧写类型名（屏幕共享、群公告……），右侧放操作。
4. **操作用不了时：永久不可用的去掉，暂时不可用的置灰。** 现有代码注释把「保留并置灰」当作设计原则，本方案改为按第 5 节的清单逐项区分。
5. **Markdown 卡片与合并转发卡片都不加按钮**，点整张卡片打开（对比页第 22 张画的「预览」按钮不做）。
6. **消息记录窗、聊天记录管理器、合并记录查看窗里的文件、代码片段、Markdown 三种卡片一起改**，与聊天窗保持一致。
7. **顺序**：原定先完成《远程桌面控制权限与观看工具条方案》第 8 节再做本方案；2026-10-14 用户改为先做卡片美化。

## 2. 现状（据实证，读代码所得）

- **绘制集中在 `ChatBubble::RenderContent`**（`ChatBubble.cpp` 4641 行起，约 1450 行），按 `m_msg.kind` 分支，先画 GDI+ 形状层、再画 GDI 文字层。只有文件卡片（`ChatFileCard.cpp`，与记录窗的 `ChatFileCardControl` 共用）、代码块（`ChatCodeBlock.cpp`）、Markdown 卡片（`ChatMarkdownCard.cpp`）、语音条（`ChatVoicePaint.cpp`）单独成文件。
- **屏幕共享这一族共用 `kMsgScreenShare` 一个分支**：屏幕共享、一对一通话、群通话、群公告、群备忘、云端录像，文字由各自的 `ChatXxxCard` 算好放进 `ChatMessage`。文件共享（`kMsgFileShare`）、入群邀请、密聊邀请也用同一套几何（`kShareBubbleW` 等常量，`ChatBubble.cpp` 351～383 行）。
- **尺寸、配色各写一套**：卡片宽有 280（合并、接龙、共享一族、邀请、Markdown）、300（文件）、344（文件夹）三种；底色是 `kBubbleOther` `#F3F2EF` / `kBubbleSelf` `#FFE6D8`（`ChatBubble.cpp` 162～163 行），没有边框；按钮色、分隔线色在合并、接龙、共享三处各定义一份，取值相同。
- **按钮形态三种**：文件、文件夹是一行文字链接；共享一族、接龙是分隔线下一整行居中的按钮文字；密聊邀请被邀请方是左右两半。
- **「次要操作的灰」与「不可用的灰」几乎相同**：取消、拒绝、另存为用 `#8A8A8A`（可点），不可用的按钮用 `#B8B8B8`（共享一族，`kShareBtnDisabledText`）或 `#B8B5B1`（文件夹「重试」）。
- **多选模式下文件、文件夹的链接仍显示手型、悬停仍高亮**（`ChatBubble.cpp` 3801、3807、3428～3447 行没有判断多选），点击本身已被拦下（3143～3158 行）。

## 3. 样式规格

所有颜色、尺寸集中到一个公共头文件 `ChatCardStyle.h`，各类卡片引用同一份常量。

### 3.1 类型色（图标块与底部标签图标）

| 类型 | 颜色 |
| --- | --- |
| 屏幕共享 | `#4C6EF5` |
| 通话、群通话 | `#1F9D5A` |
| 群公告 | `#E5484D` |
| 群备忘、文件夹 | `#E8A33A` |
| 云端录像 | `#8B5CF6` |
| 文件共享 | `#0EA5B7` |
| 接龙 | `#FF7A45`（品牌橙） |
| 入群邀请 | `#2F80ED` |
| 密聊、Markdown | `#3C4654` |
| 聊天记录（合并转发） | `#6B7A90` |

图标块 36×36、圆角 9，底色为类型色 12% 不透明度，图标 20 像素、描边 1.8。图标复用 `ChatIcons` 现有的线条图标（电话、摄像机、屏幕共享、录制、入群邀请、挂锁、喇叭、日历、接龙、文件共享、磁盘、文件夹、Markdown），只新增「聊天记录」「云端录像（圆角框 + 播放三角）」两种。已结束的卡片图标块变灰（灰色 `#86868B` 的 12% 底）。

### 3.2 卡片底板

白底 `#FFFFFF`、1 像素边框 `#E9E5E0`、圆角 10、向下 1 像素的淡投影（暖灰，不透明度约 7%）。宽度统一为 300（文件夹从 344 收到 300，280 的那些放到 300）；代码片段仍按内容自适应。内边距上 14、左右 14、下 12。

### 3.3 文字层次

- 标题：14 像素半粗，`#1F2329`，行高 20，单行省略。
- 副标题（发起人、大小、成员数等）：12 像素，`#86868B`，行高 18。
- 说明块（公告摘要、备忘时间、接龙说明、合并记录预览）：浅底 `#F7F5F2`、圆角 6、内边距 7×10，12 像素 `#5E5E62`，行高 18，最多 2 行（接龙条目与合并预览按各自行数）。
- 信息行（时长、人数）：12 像素 `#86868B`，等宽数字。

### 3.4 状态标签

高 20、圆角 10、11 像素字，字前一个 6 像素圆点：

| 语义 | 文字色 / 底色 | 典型用法 |
| --- | --- | --- |
| 进行中 | `#1F9D5A` / `#E7F6EE` | 正在共享、通话中、可用、对方已接收、全部接收完成 |
| 待处理、倒计时 | `#E0631F` / `#FFF0E6` | 待接收、下载中、剩余 N 秒、邀请 7 天内有效 |
| 拒绝、重要、失败 | `#D93C3C` / `#FDEDED` | 对方已拒绝、优先级重要 / 紧急、传输失败 |
| 已结束 | `#86868B` / `#F1EFEC` | 已结束、已取消、已过期 |
| 中性提示 | `#4A6CD8` / `#ECF0FD` | 提醒全体成员、提醒 N 人 |

### 3.5 按钮

胶囊高 28、圆角 14、13 像素字，左右内边距 14，相邻按钮间距 14，在底部一行里从右往左排：

| 级别 | 用于 | 正常 | 悬停 | 置灰（暂时不可用） |
| --- | --- | --- | --- | --- |
| 主要 | 改变状态：接收、加入、同意、参与接龙、加入群聊 | 底 `#FF7A45`，白字半粗 | 底 `#F26A33` | 底 `#F1EFEC`，字 `#B4B1AC` |
| 查看 | 打开、查看、播放、打开文件夹 | 白底，边框 `#FFC3A8`，字 `#F26A33` | 底 `#FFF0E8` | 边框 `#E9E5E0`，字 `#B4B1AC` |
| 次要 | 拒绝、忽略、取消、另存为、修改我的 | 字 `#5E5E62`，无边框 | 字 `#1F2329` | 字 `#C2BFBA` |

置灰的按钮不参与命中：没有悬停效果、没有手型、点击无反应（与现在的置灰行为一致）。

### 3.6 底部一行

上方 1 像素分隔线 `#F0ECE7`，高 40，左右内边距 14。左边是类型标签（13 像素类型图标 + 12 像素 `#9A9A9F` 类型名），右边是按钮。**标题就是类型名（如「语音通话」）且没有按钮时，不显示这一行。** 左侧标签与按钮放不下时，标签以省略号截断，按钮完整保留。

### 3.7 其他

- 文件下载与上传的进度条统一为品牌橙 `#FF7A45`（现在下载是蓝色），高 4、底 `#EEEAE5`；进度条下方一行写已传 / 总大小或当前文件名与个数，右侧百分比。
- 文件类型色（文档图标）：PDF `#E5484D`、DOC/DOCX `#2F6FED`、XLS/XLSX/CSV `#1F9D5A`、PPT/PPTX `#F0662B`、FIG 与设计稿 `#A259FF`、图片 `#0EA5B7`、压缩包 `#8C6D4F`、其他 `#8A94A6`（现在只有 pdf、xlsx、docx、fig 四种有颜色）。改在 `ChatFileVisual` 里，消息记录窗的列表行跟着变。
- 代码片段：去掉外面那层 4 像素气泡边，只剩一层白卡片；头部一行浅底 `#F7F5F2`，语言名胶囊、行数、右侧「复制」。
- 语音消息不是卡片，只把未听红点从 `#D9534F` 改为 `#E5484D`。

## 4. 代码结构

- **`ChatCardStyle.h`**（新）：第 3 节的全部颜色与尺寸常量。
- **`ChatCardModel.h/.cpp`**（新，纯逻辑，可单测）：卡片种类 → 类型色、类型标签文字、图标种类；各卡片状态 → 标签语义；按钮级别的枚举与「按钮描述」结构（文字、级别、是否可用、命中后的动作），各卡片据自己的状态生成按钮列表。
- **`ChatCardPaint.h/.cpp`**（新）：底板、图标块、状态标签、三级按钮（含悬停与置灰）、底部一行（返回各按钮矩形，命中测试用同一份结果）、说明块、进度条。形状用 GDI+，文字用现有的 `chatpaint::DrawGdiText`。
- **`ChatBubble.cpp`**：各卡片分支改为调用上面三个文件；各卡片的高度函数改按新几何计算；按钮命中改用底部一行布局给出的矩形。原有的 `kShareXxx` / `kRelayXxx` / `kMergedXxx` / `kFolderXxx` 常量里与新规格重复的删掉。
- **`ChatFileCard`、`ChatCodeBlock`、`ChatMarkdownCard`**：在原文件里改，记录窗的 `ChatFileCardControl`、`ChatCodeCardControl`、`ChatMarkdownCardControl` 自动跟着变，只需核对它们的尺寸常量。
- 不改 balloonui。
