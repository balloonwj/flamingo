# 音视频通话优化方案

> 作者：balloonwj@qq.com　起草日期：2026-10-05
> 用途：记录 2026-10-05 用户提出的五项音视频通话优化、逐项确认的结论、实现分步与进度。
> 涉及一对一通话（FlamingoMedia.dll `Call/`）与群通话（`GroupCall/`，见 `docs/群音视频通话方案.md`）。

---

| 10 | 语音消息录音暂停时试听（用户追加） | 单聊与群聊相同。暂停状态下按钮为「继续」「试听」「取消」「发送」（原定还有「停止」，实现时去掉：暂停中能直接试听、取消、发送，「停止」已无必要，而且群聊窗最小宽度下五个按钮放不下）；「试听」从头播放已录的部分，按钮变成「停止试听」，计时显示播放进度；试听中点「继续」先停止试听再接着录；「发送」发出已录的全部内容 |

## 2. 设计要点

### 2.1 媒体 DLL 取头像（第 1、5 项共用）

- `IMediaHost` 新增 `GetUserAvatar(userId, MediaAvatarInfo*)`、`GetGroupAvatar(groupId, MediaAvatarInfo*)`：
  字形、底色与照片路径（照片已在本机时），与主面板列表同一口径（`DecodeAvatar`）。照片还没下载时 exe 安排下载，
  下载完成后经新增的 `IMediaModule::OnAvatarsUpdated()` 通知，DLL 重新取头像刷新已打开的窗口。
- DLL 侧新增 `Common/MediaAvatar`（照文件共享的 `CShareAvatarSource`）：向宿主取头像，用主面板同一份代码
  （`MakeMonogramAvatar` / `MakeRoundedAvatarFromFile` / `CAvatarBitmapCache`）生成位图，界面用 balloonui 的 `DuiAvatar`。
- 插件接口按「产品未发布，接口不升版」的约定直接追加方法，不加 `kApiVersion`。

### 2.2 通话中徽章（第 3 项）

- `IMediaHost` 新增 `OnCallPresence(ctype, cid, media, inCall)`：本人一对一通话接通 / 结束、本人加入 / 离开群通话时
  DLL 回报。exe 记下「本人正在与哪个会话通话」，主面板四个列表据此打标记。
- `MainPanelTreeView` 新增 `SetItemInCall(id, media)`：沿用「特别关注」「收藏」的名字后标记机制，
  在其后画绿色胶囊；宽度计入右侧占位，名字过长时先截断名字。

### 2.3 图钉固定（第 5 项）

- 通话窗固定后：`HWND_TOPMOST`；`SetResizable(false)` 让边框不再可拖，`SetButtons` 隐藏最小化、最大化按钮
  （一对一通话窗本来就没有最大化按钮）；`WM_SYSCOMMAND` 的 `SC_MOVE` / `SC_SIZE` / `SC_MINIMIZE` / `SC_MAXIMIZE` /
  `SC_RESTORE` 一律拦下（拖标题栏、双击标题栏、Alt+空格菜单、点任务栏按钮最小化最终都落到这几个命令上），
  `WM_WINDOWPOSCHANGING` 再加上 `SWP_NOMOVE | SWP_NOSIZE`，挡住 Aero Snap、Win+方向键等不经系统命令的路径。
  群通话窗最大化时点图钉会先还原再固定。判定与图钉图标在 `FlamingoMedia/Common/WindowPin`（两个窗口共用，单测 WPN1、WPN2），
  不改 balloonui。
- 一对一通话没有「对方关了摄像头」的通知：对方画面超过 2 秒（`call::kRemoteVideoStaleMs`）没有新帧，就清掉定格的最后
  一帧、显示对方头像与「对方未开启摄像头」，来了新帧立刻恢复（`call::IsRemoteVideoStale`，单测 CDL1）。本端摄像头关着时，
  本端那一路显示本人头像与「摄像头已关闭」。群通话里没开摄像头的人本来就显示头像格子；开着摄像头但还没收到第一帧时，
  画面控件里先画头像。
